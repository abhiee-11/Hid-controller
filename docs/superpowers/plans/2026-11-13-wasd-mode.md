# WASD Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fourth controller mode, **WASD**, whose page is shaped like a controller but emits ordinary keyboard reports, so games that read the keyboard can be played from a gamepad-shaped screen.

**Architecture:** The keyboard report (report ID 1) and its state (`keyboardKeys`, `keyboardModifiers`, `LaunchedEffect(keyboardState) { onKeyboardState(...) }`) already exist in `GamepadScreen`; today only the Keyboard page writes to them. This plan adds (1) a pure description of the WASD page's keys, (2) a `ControllerMode.WASD` value with its label, and (3) a `WasdStage` composable that renders that description and drives the existing state through the same `onKey`/`onModifier` handlers the Keyboard page uses. Nothing on the wire changes.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), JUnit4 unit tests, Gradle.

**Spec:** `docs/superpowers/specs/2026-11-13-wasd-mode-design.md`

## Global Constraints

- **No descriptor change and no re-pair.** This mode sends only the existing keyboard report, report ID `KEYBOARD_REPORT_ID` (1). Do not touch `COMBINED_HID_DESCRIPTOR`, `GAMEPAD_ONLY_DESCRIPTOR`, report sizes, `Btn` bits, or the profile logic.
- Every key usage must be inside `0..KEYBOARD_USAGE_MAX` (`0x00..0x65`).
- Every modifier must be one bit in `MODIFIER_BITS`.
- No analog input, no gamepad report, no tilt from this mode.
- No RGB backlight and no caps-lock indicator on this page.
- The mode must **not** appear in the first-run onboarding (`TutorialPanel` keeps its three explicit choices).
- Colours only from `PadColors`; all sizes in `dp`.
- The mode label is exactly `WASD`.

## Review Focus

- A WASD key whose usage falls outside `0x00..0x65`: the host silently ignores it, and because the descriptor is cached at pairing time the only fix is a re-pair → covered by Task 1's `every WASD key is inside the declared usage range`.
- A modifier key whose bit is not one of the eight the descriptor declares: the host never reads it → covered by Task 1's `every WASD modifier is one declared modifier bit`.
- Holding the realistic set (`Shift` + `W A S D` + `Space` + `E`): the boot report carries only six non-modifier keys, so a seventh would silently drop → covered by Task 1's `the realistic held set fits the six-key report`.
- A stored mode name that does not round-trip: the mode resets to Gamepad after the app is restarted → covered by Task 2's `a stored WASD mode round-trips`.
- A key whose label and usage disagree (e.g. `W` sending the `S` usage): wrong movement, with no error anywhere → covered by Task 1's `each letter key maps to its own usage`.

package com.hidgamepad

import org.junit.Assert.assertEquals
import org.junit.Assert.assertTrue
import org.junit.Test

/**
 * The WASD page's key layout.
 *
 * The important property is the same one the keyboard has: every key the page can press must
 * sit inside the usage range the registered descriptor already declares, and every modifier
 * must be one of the eight declared bits. A key outside them would be ignored by the host, and
 * because the host caches the descriptor at pairing time the fix would need a re-pair.
 */
class WasdLayoutTest {

    @Test
    fun `every WASD key is inside the declared usage range`() {
        val keys = wasdLayout().keys
        assertTrue("the WASD page has keys", keys.isNotEmpty())
        for (cap in keys) {
            val action = cap.action
            if (action is KeyAction.Usage) {
                assertTrue(
                    "${cap.label} usage 0x${action.usage.toString(16)} is outside 0x00..0x65",
                    action.usage in 0..KEYBOARD_USAGE_MAX,
                )
            }
        }
    }

    @Test
    fun `every WASD modifier is one declared modifier bit`() {
        for (cap in wasdLayout().keys) {
            val action = cap.action
            if (action is KeyAction.Modifier) {
                assertTrue(
                    "${cap.label} modifier 0x${action.bit.toString(16)} is not one modifier bit",
                    action.bit in MODIFIER_BITS,
                )
            }
        }
    }

    @Test
    fun `the WASD page carries the movement and action keys`() {
        val labels = wasdLayout().keys.map { it.label }.toSet()
        for (label in listOf("W", "A", "S", "D", "Space", "Shift", "Ctrl", "E", "R", "Q", "F", "Tab", "Esc", "Enter")) {
            assertTrue("$label is missing", label in labels)
        }
    }

    @Test
    fun `each letter key maps to its own usage`() {
        val expected = mapOf(
            "W" to KeyUsage.W, "A" to KeyUsage.A, "S" to KeyUsage.S, "D" to KeyUsage.D,
            "E" to KeyUsage.E, "R" to KeyUsage.R, "Q" to KeyUsage.Q, "F" to KeyUsage.F,
        )
        val byLabel = wasdLayout().keys.associateBy { it.label }
        for ((label, usage) in expected) {
            assertEquals(label, KeyAction.Usage(usage), byLabel.getValue(label).action)
        }
        assertEquals(KeyAction.Usage(KeyUsage.SPACE), byLabel.getValue("Space").action)
        assertEquals(KeyAction.Usage(KeyUsage.TAB), byLabel.getValue("Tab").action)
        assertEquals(KeyAction.Usage(KeyUsage.ESC), byLabel.getValue("Esc").action)
        assertEquals(KeyAction.Usage(KeyUsage.ENTER), byLabel.getValue("Enter").action)
        assertEquals(KeyAction.Modifier(MOD_LEFT_SHIFT), byLabel.getValue("Shift").action)
        assertEquals(KeyAction.Modifier(MOD_LEFT_CTRL), byLabel.getValue("Ctrl").action)
    }

    @Test
    fun `the realistic held set fits the six-key report`() {
        // Shift is a modifier and does not consume a key slot; the six ordinary keys fit exactly.
        val state = KeyboardState(
            modifiers = MOD_LEFT_SHIFT,
            pressedKeys = setOf(KeyUsage.W, KeyUsage.A, KeyUsage.S, KeyUsage.D, KeyUsage.SPACE, KeyUsage.E),
        )
        val report = state.encodeReport()
        assertEquals(MOD_LEFT_SHIFT, report[0].toInt() and 0xFF)
        val keys = report.slice(2..7).map { it.toInt() and 0xFF }
        assertEquals(
            listOf(KeyUsage.W, KeyUsage.A, KeyUsage.S, KeyUsage.D, KeyUsage.SPACE, KeyUsage.E).sorted(),
            keys.sorted(),
        )
        assertTrue("no key slot is empty", keys.none { it == 0 })
    }
}

A pure data file, no Compose. Reuse `KeyCap` (label, action, weight). The page is a controller: two thumb clusters with a centre column between them, and a shoulder row above.

```kotlin
package com.hidgamepad

/**
 * The WASD page's keys, grouped as the page draws them.
 *
 * A keyboard report is all this page sends, so it reuses the same [KeyCap] the on-screen
 * keyboard uses. The grouping mirrors a controller: a left thumb cluster that moves, a right
 * thumb cluster that acts, and a centre column between them. The shoulders sit above.
 */
data class WasdLayout(
    /** Left to right: the keys on the shoulder row. */
    val shoulders: List<KeyCap>,
    /** Left thumb cluster, one inner list per row, top to bottom. */
    val leftCluster: List<List<KeyCap>>,
    /** Right thumb cluster, one inner list per row, top to bottom. */
    val rightCluster: List<List<KeyCap>>,
    /** The centre column, top to bottom. */
    val centre: List<KeyCap>,
) {
    /** Every key on the page, in no particular order. */
    val keys: List<KeyCap>
        get() = shoulders + leftCluster.flatten() + rightCluster.flatten() + centre
}

/**
 * The WASD page: `W A S D` on the left thumb, the action keys a game needs on the right, and
 * `Space`/`Enter` in the middle. Every usage is inside the range the registered descriptor
 * declares, so the page costs nothing on the wire and needs no re-pair.
 */
fun wasdLayout(): WasdLayout = WasdLayout(
    shoulders = listOf(
        cap("Tab", KeyUsage.TAB),
        cap("Esc", KeyUsage.ESC),
    ),
    leftCluster = listOf(
        listOf(KeyCap("Shift", KeyAction.Modifier(MOD_LEFT_SHIFT))),
        listOf(cap("W", KeyUsage.W)),
        listOf(cap("A", KeyUsage.A), cap("S", KeyUsage.S), cap("D", KeyUsage.D)),
    ),
    rightCluster = listOf(
        listOf(KeyCap("Ctrl", KeyAction.Modifier(MOD_LEFT_CTRL))),
        listOf(cap("E", KeyUsage.E), cap("R", KeyUsage.R)),
        listOf(cap("Q", KeyUsage.Q), cap("F", KeyUsage.F)),
    ),
    centre = listOf(
        cap("Enter", KeyUsage.ENTER),
        cap("Space", KeyUsage.SPACE),
    ),
)

private fun cap(label: String, usage: Int) = KeyCap(label, KeyAction.Usage(usage))
```

- [ ] **Step 1: Add the `WasdStage` composables to `GamepadScreen.kt`**

Place them next to `KeyboardStage` (after line 1399). They render the layout from `wasdLayout()` and dispatch to the same handlers the Keyboard page uses. No backlight, no caps indicator, no Fn. Three top-level private composables: one key, one thumb cluster, and the page.

```kotlin
/** One key on the WASD page: a press-and-hold target that reports while held. */
@Composable
private fun WasdKeyButton(
    cap: KeyCap,
    modifiers: Int,
    pressedKeys: Set<Int>,
    hapticsEnabled: Boolean,
    hapticsStrength: Float,
    onModifier: (Int, Boolean) -> Unit,
    onKey: (Int, Boolean) -> Unit,
    modifier: Modifier = Modifier,
) {
    val action = cap.action
    val active = when (action) {
        is KeyAction.Modifier -> (modifiers and action.bit) != 0
        is KeyAction.Usage -> action.usage in pressedKeys
        is KeyAction.Fn -> false
    }
    KeyboardKeyButton(
        label = cap.label,
        active = active,
        hapticsEnabled = hapticsEnabled,
        hapticsStrength = hapticsStrength,
        onDown = {
            when (action) {
                is KeyAction.Modifier -> onModifier(action.bit, true)
                is KeyAction.Usage -> onKey(action.usage, true)
                is KeyAction.Fn -> Unit
            }
        },
        onUp = {
            when (action) {
                is KeyAction.Modifier -> onModifier(action.bit, false)
                is KeyAction.Usage -> onKey(action.usage, false)
                is KeyAction.Fn -> Unit
            }
        },
        modifier = modifier,
    )
}

/** A thumb cluster: a column of equal-height rows, each row splitting its width across its keys. */
@Composable
private fun WasdCluster(
    rows: List<List<KeyCap>>,
    modifiers: Int,
    pressedKeys: Set<Int>,
    hapticsEnabled: Boolean,
    hapticsStrength: Float,
    onModifier: (Int, Boolean) -> Unit,
    onKey: (Int, Boolean) -> Unit,
    modifier: Modifier = Modifier,
) {
    Column(modifier, verticalArrangement = Arrangement.spacedBy(8.dp)) {
        for (row in rows) {
            Row(
                Modifier.weight(1f).fillMaxWidth(),
                horizontalArrangement = Arrangement.spacedBy(8.dp),
            ) {
                for (cap in row) {
                    WasdKeyButton(
                        cap = cap,
                        modifiers = modifiers,
                        pressedKeys = pressedKeys,
                        hapticsEnabled = hapticsEnabled,
                        hapticsStrength = hapticsStrength,
                        onModifier = onModifier,
                        onKey = onKey,
                        modifier = Modifier.weight(1f).fillMaxHeight(),
                    )
                }
            }
        }
    }
}

@Composable
private fun WasdStage(
    modifiers: Int,
    pressedKeys: Set<Int>,
    hapticsEnabled: Boolean,
    hapticsStrength: Float,
    onModifier: (Int, Boolean) -> Unit,
    onKey: (Int, Boolean) -> Unit,
    modifier: Modifier = Modifier,
) {
    val layout = wasdLayout()
    Column(
        modifier
            .fillMaxSize()
            .clip(RoundedCornerShape(14.dp))
            .background(RGB_DECK_COLOR)
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp),
    ) {
        // Shoulder row: Tab on the left, Esc on the right, space between.
        Row(Modifier.fillMaxWidth().weight(0.7f), horizontalArrangement = Arrangement.spacedBy(8.dp)) {
            WasdKeyButton(
                cap = layout.shoulders[0], modifiers = modifiers, pressedKeys = pressedKeys,
                hapticsEnabled = hapticsEnabled, hapticsStrength = hapticsStrength,
                onModifier = onModifier, onKey = onKey, modifier = Modifier.weight(1f).fillMaxHeight(),
            )
            Spacer(Modifier.weight(2f))
            WasdKeyButton(
                cap = layout.shoulders[1], modifiers = modifiers, pressedKeys = pressedKeys,
                hapticsEnabled = hapticsEnabled, hapticsStrength = hapticsStrength,
                onModifier = onModifier, onKey = onKey, modifier = Modifier.weight(1f).fillMaxHeight(),
            )
        }
        Row(Modifier.fillMaxWidth().weight(3f), horizontalArrangement = Arrangement.spacedBy(12.dp)) {
            WasdCluster(
                rows = layout.leftCluster, modifiers = modifiers, pressedKeys = pressedKeys,
                hapticsEnabled = hapticsEnabled, hapticsStrength = hapticsStrength,
                onModifier = onModifier, onKey = onKey, modifier = Modifier.weight(1f).fillMaxHeight(),
            )
            // Centre column: Enter on top, Space filling the rest as a wide bar.
            Column(Modifier.weight(1.2f).fillMaxHeight(), verticalArrangement = Arrangement.spacedBy(8.dp)) {
                WasdKeyButton(
                    cap = layout.centre[0], modifiers = modifiers, pressedKeys = pressedKeys,
                    hapticsEnabled = hapticsEnabled, hapticsStrength = hapticsStrength,
                    onModifier = onModifier, onKey = onKey, modifier = Modifier.weight(1f).fillMaxWidth(),
                )
                WasdKeyButton(
                    cap = layout.centre[1], modifiers = modifiers, pressedKeys = pressedKeys,
                    hapticsEnabled = hapticsEnabled, hapticsStrength = hapticsStrength,
                    onModifier = onModifier, onKey = onKey, modifier = Modifier.weight(2f).fillMaxWidth(),
                )
            }
            WasdCluster(
                rows = layout.rightCluster, modifiers = modifiers, pressedKeys = pressedKeys,
                hapticsEnabled = hapticsEnabled, hapticsStrength = hapticsStrength,
                onModifier = onModifier, onKey = onKey, modifier = Modifier.weight(1f).fillMaxHeight(),
            )
        }
    }
}
```

            ControllerMode.WASD -> {
